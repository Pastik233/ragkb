# JVM 运行时内存区域

堆是所有线程共享的区域，存放对象实例，也是垃圾回收的主要场所。堆在逻辑上分新生代和老年代，新生代又分 Eden 和两个 Survivor，默认比例 8:1:1。

虚拟机栈是线程私有的，每个方法调用创建一个栈帧，存放局部变量表、操作数栈、动态链接和返回地址。栈深度超过限制抛 StackOverflowError，栈扩展申请不到内存抛 OutOfMemoryError。

方法区在 JDK 8 之后由元空间实现，使用本地内存而不是堆内存。JDK 7 的永久代受 `-XX:MaxPermSize` 限制，容易抛 PermGen space；元空间默认不设上限，只受物理内存约束，可以用 `-XX:MaxMetaspaceSize` 限制。字符串常量池在 JDK 7 就已经从永久代移到了堆里。

程序计数器是唯一不会抛 OOM 的区域，它记录当前线程执行的字节码行号。

直接内存不属于 JVM 运行时数据区，但通过 DirectByteBuffer 分配，NIO 的零拷贝依赖它。它不受堆大小限制，但受物理内存限制，堆外内存泄漏比堆内更难排查。设置 `-XX:MaxDirectMemorySize` 可以在申请超限时尽早暴露问题。
